## Object-Oriented Programming

__Class__: A template that allows to make many object instances

__Attribute__: Variable(s) attached to the object

__Method__: Function(s) associated with the class

__Constructor__: Creates a new object instance(s)

__Getter__: Returns attribute value(s)

__Setter__: Defines attribute values

>[!important]
>If the attribute name has a name starting with an underscore, this means "please use a method instead of accessing this directly"

__Validating data__: Making sure it's the right type and range for its intended use

__Raise__: Creating a unique exception to the code

## Pass By Reference and Objects
>*Everything in Python is actually an object, and Python is actually pass-by-reference with everything...If you assign from one variable to another, then change one of the variables, the other will appear to change as well - because both variables are pointing to the same data in memory
