# XI
## Numpy
__Numpy__: Numerical Python Package

### NumPy Arrays

__NumPy Array__:
- Intended to allow fast numerical calculations
- typed
- multidimensional (set to n dimensions when initialized)
- accessible with bracket notation and indices

#### Broadcasting
>*The term broadcasting describes how NumPy treats arrays with different shapes during arithmetic operations...Broadcasting rules apply when performing these operations between arrays and numbers*

#### Axis
__Axis__: 0 (for columns), 1 (for rows)

#### Slicing
__Slicing__: Grabbing values between particular indices

>*...slicing...produces a view of the original data rather than copying the data into a new place. This means modifications to the slice will also modify the original data.*
