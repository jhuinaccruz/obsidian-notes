__Aesthetic__: The process of changing a theoretical value into a visual graphic
- Defines the glyphs being represented

__Glyph__: A single visual graphic representing a single value

__Guides__ (Legends): Provides context into reading and understanding the graph's values

__Facets__: Groups of graphs next to each other
- Used to display levels of categorical variables

__Histogram__: Univariate continuous model for summarizing the distribution of a numeric variable

__Density Plot__: Similar purpose to a histogram
- Unlike the histogram, in R the density plot uses a *kernel smoother* (estimating function of the weighted average of neighboring points)

__Bar Graph__: Display the distribution of a categorical variable

__Stacked Bar Plot__: Univariate model to display the distribution of a continuous variable

__Scatterplot__: Bivariate display of quantitative (or numerical) variables across many cases

__Box-and-Whisker Plot__: Used to map a numerical response variable against a categorical explanatory variable

__Mosaic Plot__ (Eikosogram): Used to visualize two categorical variables against each other

__Map__: Geographical display of data

__Network__: A display of connections between nodes (edges and vertices)
