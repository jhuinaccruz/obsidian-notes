>*Some `geom`s compute statistics from the data before plotting them*

__Stat Geoms__: Compute statistics from provided data before plotting
- Standard geoms plot values one-to-one
- Examples include:
	- `geom_smooth()`: Fits a statistical model and calculates standard errors
	- `geom_bar()`: Counts the number of rows for each category
	- `geom_boxplot()`: Calculates median, 25th and 75th percentile (Q1, 3), and whiskers
	- `geom_histogram()`: Bins continuous data into intervals and counts how many data points fall into each bin.
	- `geom_density()`: Estimates a smooth, continuous probability density function
