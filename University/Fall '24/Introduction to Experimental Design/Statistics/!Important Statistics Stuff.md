## Lecture VII

**Descriptive statistics**: give a concise and understandable overview of the data

#### Measures of Variablity

>[!info]
>__N__(umber of data points) = __Frequency__ / __Relative Frequency__

__Frequency__: the max amount that a number appears in a data set
> Frequency = N(umber of data points) * relative frequency

__Relative Frequency__: the proportion of the amount a value appears in relation to the data set
> Relative Frequency = Frequency / N

__Joint Frequency__: the frequency with which two values occur *together*

__Joint Relative Frequency__: the frequency with which two values appear *together* in relation to the data set

## Lecture VII

__Marginal Frequency__: (only for two-categorical variable tables) frequency of a *single category* in a data set
> sum all the appearances of a categorical variable across the table

__Marginal Relative Frequency__: (only for two-categorical variable): frequency of a *single category* in a data set in relation to the data set

__Conditional Relative Frequency__: calculates frequency *in relation to* the data set

>[!important]
>*Data visualization helps us understand data, because statistics is about communication*

__Stacked Bar Chart__: presents *two* categorical variables by stacking bars representing subcategories *within* the categorical variables

>[!important] 
>for __Stacked__ Bar Charts
>*They are best used when you want to compare total count of a main category and see the compositions within it*

__Grouped Bar Chart__: presents subcategories as bars *grouped* next to each other within a category

>[!important]
>for __Grouped__ Bar Charts
>*They are best used when you want to compare subcategories with side-by-side comparison rather than stacked data*

__Pie Chart__: presents a circular visualization of proportions within a *single* category

>[!important]
>for __Pie__ Charts
>*They are best used when you want to highlight how a single category is divided into parts*

__[[Central Tendency]]__: the statistical measurement of the center in a data set

__[[Variability]]__: the measurement of spread in a data set

__[[Shape]]__: the measurement of pattern in a data set


## Lecture X

__Deduction__: reasoning from general principles to specific cases

__Induction__: reasoning from specific observations to general conclusions

>[!important]
>Deduction is *general* to *specific*, whereas induction is *specific* to *general*

__Statistical Inference__: focuses on drawing conclusions about a population based on data obtained from a sample

__Descriptive Statistics__: summarizes the data *as it is*

__Inferential Statistics__: generalizes the data into inferences about the world

__Population__: the entire group of individuals of interest
- __Finite Population__: a population with a fixed and countable number of elements
- __Infinite Population__: a population that is so large it is treated as "conceptually infinite"

__Sample__: the subset of the population selected for analysis

Correlation Formula (__Pearson's Correlation Coefficient__)
$$
r = \frac {\sum(X_i - \overline{X})(Y_i - \overline{Y})} {\sqrt{\sum(X_i - \overline{X})^2} \sum(Y_i - \overline{Y})^2}
$$
where r is Pearson's correlation coefficient

T-statistic formula
$$
t = \frac
	{r \sqrt{n-2}}
	{\sqrt{1-r^2}}
$$
where t is the t-statistic
where r is Pearson's Correlation Coefficient
where n is the number of pairs of scores/sample size
