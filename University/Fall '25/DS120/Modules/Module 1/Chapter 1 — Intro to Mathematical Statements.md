__∀__: For all

__∈__: Belongs to

__R__: A set of real numbers

__∩__: Denotes an intersection of sets

__⊆__: A subset of

__Set__: A collection of objects without duplicates

__∃__: There exists

__.__: Such that

__Truth Value__: Either true or false

__Mathematical Proposition__: A grammatically-correct statement containing words, symbols, and/or mathematical notations that can be evaluated as either true or false

__Variable Proposition__: Similar to a mathematical proposition, with the addition of variable(s) that determine the true/false value of the statement

>*We can often represent a claim/proposition as a mathematical statement by using upper case letters along with the involved variable in brackets*

__Conjecture__: An unproven mathematical proposition

__Universal Quantifier__: A claim that holds for every case within a set, denoted by ∀

__Existential Quantifier__: A claim that holds for some cases within a set, denoted by ∃

__N__: A set of natural numbers

__Z__: A set of integers

__Q__: A set of rational numbers

__I__: A set of imaginary numbers
