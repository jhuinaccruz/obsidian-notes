__Big O Notation__: Describes how runtime and memory grows as input size grows, focusing on time growth rate as n approaches infinity
- `O(n)`: Linear time
- `O(n^2)`: Quadratic time
- `O(log(n))`: Logarithmic time 
- `O(2^n)`: Exponential time
- `O(1)`: Constant time
- `O(1)` < `O(log n)` < `O(n)` < `O(n log n)` < `O(n^2)` < `O(2^n)` < `O(n!)`

__Best Case__: Result of a function with its most ideal input

__Worst Case__: Result of a function with its least ideal input

__Average Case__: Result of a "normal" input

__P__ (Polynomial Time): Solvable in `O(n^k)` for some constant `k`, such that they are considered efficiently solvable

__NP__ (Nondeterministic Polynomial time): Can only have solution verified in polynomial time, but their solutions are considerably harder
