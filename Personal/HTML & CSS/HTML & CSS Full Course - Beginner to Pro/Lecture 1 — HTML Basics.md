__Syntax__: Rules for writing code

__Tag__: Dictates what element is being created, denoted by `<Tag>`
- Must have an opening tag `<Tag>` and a closing tag `<\Tag>`

__Anchor__: Used to either
- Create external links
- Link a section to itself
- Trigger an action (call, email, etc.)

__Attribute__: Modifies how an element behaves
- Must be separated from the tag by spaces

>*Extra spaces in HTML are ignored*
