__Structured Query Language__ (SQL): Used for interacting with databases

__Database__: Stores information in an organized way, where the queries to access the data are often written in SQL

__Relational Database Management System__ (RDBMS): Treats data as being organized in tables

>*An interesting aspect of SQL is that a query specifies what it wants, but not how to get it*

>*SQLite...gives us the power to make SQL queries against an existing database and put the result in a Pandas dataframe*

>*SQLite compiles the query into a program, and chooses among multiple approaches to get the data. As a result, what the engine is doing is often treated like a black box by the user*
