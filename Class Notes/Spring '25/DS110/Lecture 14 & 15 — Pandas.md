>*Pandas is a python package that deals mostly with:*
>- Series (1-D homogenous array)
>- DataFrame (2-D labeled heterogenous table)
## Series
>*A Pandas series is a 1-dimensional labeled array containing data of the same type (integers, strings, floating point numbers, Python objects, etc).*

__Index__: Explicit axis of Pandas series
## DataFrame
>*The fundamental object that you interact with in Pandas is a DataFrame. A Pandas DataFrame is a 2-dimensional, size-mutable, heterogenous tabular data structure with labeled rows and columns.*

>*You can think of it as a dictionary-like container to store Python Series objects*

>*DataFrames also have functionality for dealing with more messy data, with missing values and different data types mixed in the same object.*
