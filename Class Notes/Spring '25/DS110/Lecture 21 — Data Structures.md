## Trees
>Trees are made of tree nodes. They are structurally similar to linked lists except tree nodes can have multiple children.

>*A tree node is like a linked list node wtih multiple "next nodes", called "children" in this context.

__Parents__: Nodes pointing to children

__Root__: Node with no parent

__Leaves__: Node with no children

>*Trees can serve a vareity of purposes in code, like:*
>- *Representing filed and folders - children are contained in parent folders*
>- *Representing a hierarchy in an organization*
>- *Representing possible sequences of actions, like in a game*
>- *Forming the basis for specific fast data structures (like "heaps")*
>- *Representing a decision process for an AI/Machine Learning system*

>*Recursion is a very natural day to do things with trees, and various tasks like counting all the nodes in the tree or determining the depth of the tree (the maximum distane to the root) are most easily performed with recursion*
