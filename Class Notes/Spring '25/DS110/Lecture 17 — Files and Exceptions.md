__JSON__: Stands for JavaScript Object Notation, its a popular to transfer key-value pairs

>*Values in JSON objects can be strings, numbers, Boolean values (written in lowercase), null, arrays, or other JSON values*

__Serialization__: Committing data to a file

__Pickling__: A Python-specific method of serialization
	Considered to be too powerful for most applications, rejected in favor of platform-independent formats of serialization
## Intro To Exceptions
>*Exceptions are objects, and there are multiple kinds depending on the error that occurred*

__Exception Objects__:
- FileNotFoundError
- ZeroDivisionError
- ValueError

>*if an error occurs and isnt "caught", the program immediately terminates, reporting where the error occurred*
