__Square Matrix__: Where in an m\*n matrix, m=n

__Generally, a matrix is denoted by \_, and the elements by \___: Bold phase lettering, lowercase lettering with subscripts

$$
a_{ij}
$$
where (when denoting elements in a matrix)
- i = row it can be found at
- j = column it can be found at

__Zero Matrix__: Where all the elements in a matrix are zero

## Matrix and Vector Operations

__Equality__: Two matrices A and B are equal such that
$$
a_{ij} = b_{ij}
$$
where:
- a = element at matrix A
- b = element at matrix B

__Addition__: Where summing two matrices A and B results in a new matrix C such that
$$
c_{ij} = a_{ij} + b_{ij}
$$
where:
- c = element at matrix C

__Scalar Product__: Multiplying each element of a matrix with a scalar k such that
$$
kA = (ka_{ij})
$$
__Vector Length__ (Magnitude): Calculated by by taking the square root of the sum of the squares of the components;
$$
|\vec{v}| = \sqrt{{v_1^2} + {v_2^2} + ...{v_n^2}}
$$

__Unit Vector__: A vector with a magnitude of 1

__Dot Product__: Combining two vectors such that
$$
\vec{a}.\vec{b} = a_1 . b_1 + a_2 . b_2 ... + a_n . b_n
$$
or
$$
\vec{a}.\vec{b} = |\vec{a}||\vec{b}|\cos{\theta}
$$
__Matrix Multiplication__: Multipliable only if the number of columns of matrix A is the same as the number of rows of matrix B such that
$$
C = A_jB_i
$$
where:
- A_j is the number of columns of A
- B_i is the number of rows of B

__Orthogonal__: When vectors have an angle of 90 degrees between them such that the dot product of a and b is 0
$$
0 = a.b\cos(\theta)
$$
