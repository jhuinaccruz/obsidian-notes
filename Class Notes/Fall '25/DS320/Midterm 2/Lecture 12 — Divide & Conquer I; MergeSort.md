__Divide and Conquer solutions__: An approach that allows for designing efficient algorithm design through
- Identifying subproblems into which the main problem can be divided, then solving them recursively and combining their solutions
1. Define the recursive subproblem in plain English (what the subproblem means, its parameters, etc.)
2. Define base cases
3. Present the recursive cases: Give a mathematical definition of the subproblem in terms of smaller subproblems
4. Prove correctness by arguing that the base cases return the correct result, then (at the inductive step) argue why the recursive cases combine to solve the larger problem
5. Prove running time
