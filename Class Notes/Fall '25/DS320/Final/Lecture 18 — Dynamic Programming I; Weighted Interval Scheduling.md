__Dynamic Programming__: Solve each problem once and store its solution to prevent redundant calculations and improve efficiency
- __Principle of Optimality__: An optimal solution to a problem contains the optimal solution of its subproblems

__Dynamic Programming Algorithm Proof__:
1. __Define the subproblem__ (in plain English), denoting what "optimal" means
2. __Present the recurrence__
3. __Prove the recurrence is correct__
4. __State and prove the base cases__
5. __State how to solve the original problem__
6. __Present the algorithm__
7. __Define the running time__:
	- Pre-processing
	- Filling in the memoization table
		- Define the number of entries
		- Time to fill in each entry
	- Post-processing
