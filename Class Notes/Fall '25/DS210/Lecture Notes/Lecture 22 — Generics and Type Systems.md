__Dynamic Typing__: Types are checked at runtime, which allows for flexible coding but is prone to runtime errors

__Static Typing__: Types are checked at compilation, such that it leads to fast execution with early error detection

__Polymorphism__: When a function is able to take multiple forms and multiple different inputs

__Monomorphism__: When Rust's compiler makes individual functions

__Zero Cost Polymorphism__: Means that there is no runtime type checking/guessing, leading to no performance penalty compared to writing separate functions by hand
