__Stack__: Last in, First Out structure (LIFO)

__Queue__: First in, First Out structure (FIFO)

__Deque__: Double Ended Queue

__Linked List__: A set of nodes where each nodes contains its data and a pointer to the next element

__Sequential Collections__: Elements stored in order by their value, accessed by their index

__Hash-based Collections__: Elements stored in order determined by its inherent hash value, accessed by a key (map)/value equality (set)
