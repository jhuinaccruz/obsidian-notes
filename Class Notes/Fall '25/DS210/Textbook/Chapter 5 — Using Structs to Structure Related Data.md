>[!abstract]
>*In this chapter, we’ll compare and contrast tuples with structs to build on what you already know and demonstrate when structs are a better way to group data.*

>*If you’re familiar with an object-oriented language, a struct is like an object’s data attributes.*

__Struct__ (Structure): Similar to tuples, a custom data type that lets you package together and name multiple related values that make up a meaningful group
- Unlike tuples, each piece of data is named for clarity

__Method__: Defined within the context of a struct, enum, or trait object, similar to functions
