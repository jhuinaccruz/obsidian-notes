__Grammar of Graphics__: Coherent system for describing and building graphs

__Observation__: Set of measurements made under similar conditions
- All the attributes of a single trial/object

__Tabular Data__: A set of values, each value associated with another variable (label) and an observation (result)

>*Tabular data is tidy if each value is placed in its own “cell”, each variable in its own column, and each observation in its own row.*

__Canonical Data Graphics__: Fundamental visual representations of quantitative relationships
- In R, represented by __geoms__ (geometric objects) and the corresponding functions (`geom_*`)

__Scaling__: The assignment of a unique aesthetic value (e.g. color) to each unique variable level

__Numerical__ (Quantitative): Values that can be performed operations such as adding and multiplication to
