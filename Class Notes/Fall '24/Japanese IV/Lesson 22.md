## 1. Causative Forms
>*In this lesson, we learn yet another verb derivation called the “causative form” When you use the causative form of a verb, you can describe who makes someone do something, and who lets someone do something.*

| verb   | causative form |
| ------ | -------------- |
| う-verb | 〜あせる           |
| る-verb | 〜させる           |
| 来る     | こさせる           |
| する     | させる            |
## 2. Commands
>*The verb stem + なさい^ is a command, has a strong implication that you are “talking down” to somebody, or that you think you are more mature, know better, and should be obeyed.*

## 3. A ば B
>*“Clause A ば clause B” is a conditional statement “if A, then B.”*

| verb        | ば-form                     |
| ----------- | -------------------------- |
| affirmative | remove the last う, add えば  |
| negative    | remove the last う, add ければ |
>[!important]
>*You usually use the “A ば B” pattern when the condition “A” guarantees a good result in “B”*
## 4. B, In Spite of A
>*のに connects two facts, A and B, which hold in spite of the expectation that if A is the case, B is not to be the case.*

## 5. 〜のような・〜のように
>Noun のような X means the noun is like X

>Noun のように X means the noun is done in a similar way to X (X is a verb)
