>[!quote]
>According to Gemini
>
>*Central tendency is a statistical concept that refers to the typical or central value within a dataset. It provides a single value that aims to describe the entire dataset, giving you a general idea of where most of the data points lie.*

There are different kinds of methods used to measure this such as:

- __Mean__
$$
\bar{y} = \frac{total}{n} = \frac{\sum{y}}{n}
\space
$$
- __Median__ (middlemost data point)
- __Mode__ (most reccuring data point)
