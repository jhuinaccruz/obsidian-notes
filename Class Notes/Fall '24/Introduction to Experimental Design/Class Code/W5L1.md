```run-r{pre}
data("bfi")

```
## Bivariate Plot
```run-r
# Create a boxplot of age by gender
# Create a boxplot of age by gender
boxplot(age ~ gender,         # Formula notation: age is plotted against gender
        data = bfi_n,           # Specify the data frame to use
        main = "Box Plot of Age by Gender",  # Main title of the plot
        xlab = "Gender",     # Label for the x-axis
        ylab = "Age",        # Label for the y-axis
        col = c("lightblue", "lightpink"),  # Colors for the boxplots
        border = "darkblue") # Border color for the boxes
```
