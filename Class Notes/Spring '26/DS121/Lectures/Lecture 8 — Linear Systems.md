__Linear Equation__: Written in the form
$$
a_1x_1 + a_2x_2 + ... + a_dx_d = b
$$

__System of Linear Equations__: A collection of one or more linear equations
- Its solution is a list of numbers that makes each equation a true statement when said list of numbers are replaced into their respective variable
- Equivalency between systems is defined by their shared solution set

__Solution Set__: The set of all possible solutions

__Consistency__: In linear systems, defined as a solution set with either one or infinitely many solutions
- Conversely, an inconsistent solution is no solution

>*Geometrically, we can find the solution to a system of linear equations in `d` variables by creating a graph showing the solution space to each individual equation in a `d-1` dimensional space*

>*A single solution will be denoted by the intersection of non-parallel lines, whereas no solution will show parallel lines, and an infinite solution set shows two lines with the same slope and intercept.*

__Span__: Denoted by
$$
\exists a_1,...,a_k.\ a_1 \in \mathbb{R}^d \implies \text{Span}\{ a_1,...,a_k\}
$$
where the subset of `R^d` is spanned by the set of vectors `a_1,...,a_k`
