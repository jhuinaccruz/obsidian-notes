__Linear Dependence__: A set of vectors denoted by the following
$$
\{v_1, ..., v_p\} \in \mathbb{R}^p.\  x_1v_1+...x_pv_p = 0 \iff x_1 = c_1,...,x_p = c_p
$$
where at least one of the scalars c are non zeroes

__Linear Independence__: A set of vectors denoted by the following
$$
\{v_1, ..., v_p\} \in \mathbb{R}^p.\  x_1v_1+...x_pv_p = 0 \iff x_1 = c_1,...,x_p = c_p
$$
where there is only one solution at `x_1 = 0`...`x_p = 0`

__Spanning Set__: A set of vectors denoted as
$$
V \subset \mathbb{R}^d
$$
such that they can be expressed as a linear combination of the vectors in this set

__Basis__: The minimum amount of vectors needed to be a spanning set

__Dimension__: The number of vectors in a basis
